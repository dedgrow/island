# Island

Плашка в духе «динамического острова» для Windows 10/11: сверху экрана, «жидкая», полупрозрачная.

- Играет музыка — маленькая плашка с обложкой и прыгающими столбиками.
- Мышь у верхнего края экрана по центру или на плашке — раскрывается: обложка, трек, исполнитель, часы, погода, кнопки ⏮ ⏯ ⏭
  и полоска прогресса со временем (клик по ней — перемотка).
- Цвет столбиков и полоски берётся из обложки, фон слегка окрашивается под неё.
- Новый трек — сама раскрывается на 4 секунды.
- Ничего не играет — спрятана.
- Работает с любым плеером, который виден в медиа-панели Windows (Яндекс Музыка, Spotify, браузер…).

## Запуск

Нужен Python 3 и Pillow:

```
pip install pillow
pythonw island.py
```

Или двойной клик по `start.bat`. Закрыть — правый клик по острову.

Автозапуск: положи ярлык на `pythonw.exe island.py` в папку `shell:startup`.

## Настройки

В начале `island.py`:

- `LAT, LON` — город для погоды (по умолчанию Москва);
- `BG_ALPHA` — прозрачность фона (255 — непрозрачный);
- `BIG`, `PILL` — размеры раскрытого острова и маленькой плашки.

## Как устроено

- `island.py` — окно и отрисовка (Pillow + прозрачное окно Windows через `UpdateLayeredWindow`).
- `media.ps1` — берёт трек у Windows и передаёт ему команды play/next/prev.
- `CoverReader.cs` / `CoverReader.dll` — читает обложку (Windows PowerShell 5.1 сам не умеет).
  Пересобрать: `csc /target:library` со ссылками на `System.Runtime.WindowsRuntime.dll` и `Windows.winmd` из Windows SDK.
- Погода — [Open-Meteo](https://open-meteo.com/), без ключа.
