# Island

Плашка в духе «динамического острова» для Windows 10/11: сверху экрана, «жидкая», полупрозрачная.

- Играет музыка — маленькая плашка с обложкой и прыгающими столбиками.
- Мышь у верхнего края экрана по центру или на плашке — раскрывается: обложка, трек, исполнитель, часы, погода, кнопки ⏮ ⏯ ⏭
  и полоска прогресса со временем (клик по ней — перемотка).
- Плееры отдают Windows маленькую обложку (Яндекс — 150×150), поэтому остров ищет ту же в 600×600 через поиск Apple
  (уходят только название и исполнитель) и берёт её, только если она совпадает с обложкой от плеера.
- Цвет столбиков и полоски берётся из обложки, фон слегка окрашивается под неё.
- Новый трек — сама раскрывается на 4 секунды.
- Ничего не играет — спрятана.
- Под исполнителем видно, какой плеер играет.- Раскрытый остров не мешает: клик мимо кнопок, полоски, часов и обложки уходит в окно под ним.
- Колёсико мыши над островом — громкость.
- Клик по часам — таймер +5 минут (каждый клик добавляет ещё 5); по окончании — сигнал и «Время вышло!».
- Скопировал текст — на секунду всплывает «Скопировано».
- На рабочем столе по центру — «жидкий» квадрат с обложкой: вытекает, пока играет музыка, края размыты, снизу капает. Окна его закрывают.
- Караоке (вкл в меню): на квадрате внизу обложки текущая строка песни заливается по ходу, под ней — следующая. Сверху можно показать название трека и исполнителя (тоже в меню). Текст с таймингом — из [LRCLIB](https://lrclib.net/) (уходят только название и исполнитель).
- Правый клик — меню: таймер, непрозрачность, цвет темы (под обложку или свой), квадрат с обложкой вкл/выкл, караоке и название на квадрате вкл/выкл, город для погоды, выход. Выбор сохраняется в `settings.json`.
- Работает с любым плеером, который виден в медиа-панели Windows (Яндекс Музыка, Spotify, браузер…).

## Запуск

Нужен Python 3 и Pillow:

```
pip install pillow
pythonw island.py
```

Или двойной клик по `start.bat`. Закрыть — правый клик по острову → «Выход».

Автозапуск: положи ярлык на `pythonw.exe island.py` в папку `shell:startup`.

## Настройки

В начале `island.py`:

- `LAT, LON` — город для погоды (по умолчанию Москва);
- `BG_ALPHA` — прозрачность фона (255 — непрозрачный);
- `BIG`, `PILL` — размеры раскрытого острова и маленькой плашки.

## Как устроено

- `island.py` — окно и отрисовка (Pillow + прозрачное окно Windows через `UpdateLayeredWindow`).
- `media.ps1` — берёт трек у Windows и передаёт ему команды play/next/prev.
- `CoverReader.cs` / `CoverReader.dll` — читает обложку (Windows PowerShell 5.1 сам не умеет).
  Пересобрать: `csc /target:library` со ссылками на `System.Runtime.WindowsRuntime.dll` и `Windows.winmd` из Windows SDK.
- Погода — [Open-Meteo](https://open-meteo.com/), без ключа.
